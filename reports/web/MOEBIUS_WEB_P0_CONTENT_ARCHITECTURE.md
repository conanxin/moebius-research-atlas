> Mœbius Research Atlas · 架构 P0 阶段
> 副标题：A Digital Study of Visual Language, Space, Information and Narrative
> 2026-09-16 · 仅为研究地图 / 档案 / 科幻出版物气质的低复杂度研究型页面；不写最终 HTML

---

## 一、页面目的

展示"如何通过系统阅读、跨作品比较、盲读、反例测试和证据管理逐步形成并修正对 Mœbius 的理解"。

不是：
- biography / works catalog / image wall / eulogy / fandom page

而是：
- 研究过程的可见化（research process made visible）
- 可证伪假说 + 已冻结证据链 + 已记录失败案例
- 跨年代 / 跨项目 / 跨假说的对照矩阵

## 二、目标读者

- 已熟悉 Mœbius 作品、希望检视其视觉语言研究方法的读者
- 研究漫画/图像叙事的学者（comics studies、图像研究）
- 本研究自身的 reviewer（cross-decade / fresh-context replication）
- 偶尔有：粉丝 / 学生，但不会被页面对其做知识简化

### SECTION 10 · Research Method

**协议链**：
```
IDENTITY GATE
→ SAMPLE FREEZE
→ FRESH VISION
→ LEDGER
→ HYPOTHESIS
→ COUNTEREXAMPLE
→ LOCK
```

**三个"== ≠"纪律**（具体失败案例支持）：
1. **keyword-clean != hypothesis-blind**
   - 案例：PHASE6B_BODY_AS_NARRATIVE_RESOURCE_BUNDLE.zip（V1）通过 literal contamination check 但 README 含 "身体先于解释 / 叙事资源" 语义泄露 → V2/V3 中性版本
2. **programmatically contiguous != narratively contiguous**
   - 案例：Phase 6B SAMPLE_FREEZE_ROUND1_STATUS=INVALIDATED_BY_CORPUS_BOUNDARY_ERROR（程序采样 scan 208-287 STEL，但实际含 front matter + chapter title + Moebius prose → R2 重新独立验证 scan 211-284）
3. **A_CONFIRMED work identity != canonical visual asset**
   - 案例：Phase 5C Cristal Saga — works.jsonl 中 W-CS-PLATE-A/B 的 local_path 映射本身污染；A_CONFIRMED 是作品级身份，不担保 linked local_path 是单件作品正面资产；asset_role 必须逐文件独立裁定

**Evidence card**：
- CLAIM：研究方法可证伪
- SUPPORTING：上述三个失败案例
- REPORT：METHODS/MOEBIUS_ARCHIVE_RESEARCH_PROTOCOL.md + studies/PHASE6B_RESULT_SYNTHESIS.md + Phase 5C 14C 资产教训
- VERDICT：方法链已建立 + 三教训已立
