# Public Research Data

Release-level research data for Research Atlas.

## Files
- `atlas-works.json` — Works referenced by the Atlas (minimal metadata)
- `atlas-claims.json` — Claims, status, scope, limitations
- `atlas-evidence.json` — Claim → work → asset mapping
- `public-assets.json` — Public visual asset list
- `public-assets.csv` — Same, CSV form

## Not included
- Internal session logs
- Agent reasoning transcripts
- Full ledger dumps
- Large raw downloads
